# Preferences

- 文件与目录命名一律 kebab-case，不为任何语言/框架的 PascalCase 或 snake_case 惯例开豁免；唯一例外是语言语法强制处——Python 的 module 与 package 名 MUST 用 snake_case（`import my-mod` 是语法错误）
- 代码内标识符命名见 naming-conventions skill
- 源代码禁止 emoji；注释与日志输出确需使用时须明确标注原因
- 注释、commit message、文档正文以英文为主；面向用户的对话不受此约束
- commit message 的格式与结构见 commit-lite skill
