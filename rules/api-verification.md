# API Verification

写第三方库调用前，先判项目内有无先例——训练数据里的过时写法与当前写法同样流畅，
主观确定感不是可靠信号。

- 先例 = 同一库同一 API 的真实调用点，grep/LSP 可验；相似 API 不算
- 有先例：照既有写法写
- 无先例：MUST 查证后再写，MUST NOT 凭记忆
- 即使有先例也 MUST 查证的两种情况：依赖刚升过大版本（先例可能是旧版写法）；
  要用的能力先例未覆盖（先例只调了 A，你要用 B）
- 查证走 tooling rule 的检索链，命中即停
- 报错信息、类型签名、既有代码是一手证据，优先于任何文档描述
